Public API reference ​

The package entry point (@busmap/table) exports the symbols below. TanStack-derived types and functions are direct re-exports from @tanstack/react-table@9.3.1; they are not wrapped or modified. The stylesheet is a separate package export: @busmap/table/style.css.

ResizableTable ​

ResizableTable<TData> renders the current TanStack row model and its resizable columns inside a scroll container.

ts
type ResizableTableProps<TData extends RowData> = {
  table: ReactTable<typeof resizableTableFeatures, TData>;
  label: string;
  getRowProps?: (row: Row<typeof resizableTableFeatures, TData>) =>
    ComponentPropsWithoutRef<"tr">;
  renderHeaderExtra?: (
    header: Header<typeof resizableTableFeatures, TData>
  ) => ReactNode;
  renderSortIndicator?: (direction: "asc" | "desc") => ReactNode;
  virtualize?: boolean;
  className?: string;
  style?: TableCSSProperties;
  pixelFallback?: PixelFallback;
  columnWeights?: ColumnWeights;
  onColumnWeightsChange?: (weights: ColumnWeights) => void;
};
PropRequiredDefaultBehavior
tableYes-TanStack table configured with resizableTableFeatures.
labelYes-Accessible name applied to the table.
getRowPropsNo-Returns standard <tr> props for each row. It does not implement selection or keyboard behavior.
renderHeaderExtraNo-Returns extra React content for each header. A truthy result marks the header with the timeline-header style.
renderSortIndicatorNoDefault chevronReturns a custom decorative header icon for the active "asc" or "desc" direction. A nullish result preserves the default. Not called for unsorted columns.
virtualizeNofalseEnables measured row virtualization.
classNameNo-Class added to the scroll container.
styleNo-Inline style for the scroll container, including TableCSSProperties.
pixelFallbackNo"last"When every column is pixel-based, expand the last or "widest" eligible resizable column.
columnWeightsNoInternal stateControlled percentage-weight overrides. Requires the change callback.
onColumnWeightsChangeNo-Receives the complete next weight map at the configured resize commit time.

Enabled leaf columns with valid resize actions receive separators. Native enableResizing, enableColumnResizing, columnResizeDirection, and columnResizeMode are honored. Column metadata chooses pixel or percentage sizing independently of permission. See the complete sizing contract for constraints, partner selection, fallback behavior, keyboard bounds, and the distinction between native size state and rendered percentage widths.

When virtualize is true, the estimated row height is 36 pixels, overscan is two rows, and rows are measured. These are implementation constants, not component props.

resizableTableFeatures ​

The feature set passed automatically by useResizableTable. It combines TanStack column sizing, column resizing, row sorting, the sorted row model, and the alphanumeric and text sort functions. It does not add application filtering, pagination, data loading, or selection behavior.

Use it directly with useTable through the features option if you need to configure TanStack Table yourself.

useResizableTable ​

ts
function useResizableTable<TData extends RowData>(
  options: ResizableTableOptions<TData>
): ReactTable<typeof resizableTableFeatures, TData>;

Calls TanStack useTable with the provided options and features: resizableTableFeatures. ResizableTableOptions<TData> is the TanStack TableOptions type for this feature set with the features property omitted. Options such as columns, data, getRowId, and table state are passed through unchanged. The hook has no package-specific defaults beyond the installed feature set.

Column sizing types ​

ts
type ColumnSizingMeta = {
  sizingMode?: "pixel" | "percentage";
  weight?: number;
};
type ColumnWeights = Record<string, number>;
type PixelFallback = "last" | "widest";

resizableTableFeatures supplies typed column metadata through TanStack's feature-scoped columnMeta option. No global module augmentation is needed. Percentage weights are finite non-negative relative shares, not native pixel state. At least one percentage column must have positive weight. Omitted mode means pixel; omitted weight means one.

TableSortControls ​

ts
type TableSortControlsProps<TData extends RowData> = {
  table: ReactTable<typeof resizableTableFeatures, TData>;
  label?: string;
  className?: string;
};
PropRequiredDefaultBehavior
tableYes-Table whose sorting state and sortable columns are controlled.
labelNo"Sort by"Accessible label for the column selector.
classNameNo-Class added to the controls group.

The component renders an unsorted option, a sortable leaf-column selector, and a direction button. The button is disabled when there is no active sort. The selector requires string headers for sortable columns.

useTableSortingControls ​

ts
function useTableSortingControls<TData extends RowData>(
  table: ReactTable<typeof resizableTableFeatures, TData>
): {
  sort: SortingState[number] | undefined;
  direction: SortOrder;
  options: TableSortOption[];
  selectColumn: (id: string) => void;
  toggleDirection: () => void;
};

type TableSortOption = { value: string; label: string };
  • sort is the first active sorting entry or undefined.
  • direction is the active direction; it is "asc" when no sort is active.
  • options starts with { value: "", label: "Unsorted" }, followed by sortable leaf columns. A sortable column with a non-string header causes an error.
  • selectColumn("") clears sorting. Selecting a valid sortable column sets the sorting state using its first sort direction. A missing or non-sortable ID throws an error.
  • toggleDirection() reverses the active sort. It does nothing when there is no active sort.

Table ​

Table is an object containing styled, ref-forwarding DOM primitives. They accept the normal props for their underlying elements and set a data-slot attribute.

MemberElementAdditional behavior
RoottableAdds table styles, role="table", and data-slot="table". TableRootProps is the normal table props type.
ScrolldivScroll container; slot table-scroll.
HeadertheadSlot table-header.
HeaderRowtrSlot table-header-row.
HeadthSets scope="col", role="columnheader", and slot table-head. Accepts timeline?: boolean for timeline header sizing.
HeaderLabelspanSlot table-header-label.
SortIndicatorspanAccepts direction: false | "asc" | "desc" and optional children: ReactNode. Renders those children or the default chevron in an aria-hidden wrapper.
BodytbodySlot table-body.
RowtrSlot table-row.
CelltdSets role="cell" and slot table-cell. Accepts numeric?: boolean for numeric alignment.
SeparatordivSlot table-separator; the primitive alone does not resize columns.
FooterdivSlot table-footer.

Only TableRootProps is separately exported for these primitives. Head, Cell, and other primitive component prop types are inferred from the underlying elements; timeline and numeric are the additional props on Head and Cell.

These primitives provide styles and basic semantics, not data mapping, sorting, resizing, virtualization, or interaction state. Those behaviors remain the consumer's responsibility unless ResizableTable is used.

resizeColumnPair ​

ts
function resizeColumnPair(
  left: number,
  right: number,
  delta: number,
  leftMin: number,
  leftMax: number,
  rightMin: number,
  rightMax: number
): [number, number];

Returns [newLeft, newRight] while transferring the requested delta between the pair and clamping it to the supplied bounds. Positive deltas increase the left width and decrease the right width. It is a pure calculation: it does not validate inconsistent bounds, access a table, or update UI state.

SortOrder ​

Enum exported with two values: SortOrder.Ascending === "asc" and SortOrder.Descending === "desc".

TanStack re-exports ​

The package also directly re-exports these values and types from @tanstack/react-table@9.3.1:

  • Values: createColumnHelper, useTable.
  • Types: ColumnDef, Header, ReactTable, Row, RowData, SortingState, TableOptions.

Their parameters, options, defaults, and behavior are those of the installed TanStack release. Use TanStack's documentation for the complete upstream API; the package adds no wrapper behavior to these exports.

Stylesheet export ​

Import @busmap/table/style.css once in the consuming app. There is no JavaScript API or runtime setup associated with this subpath.
