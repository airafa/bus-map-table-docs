@busmap/table provides a typed React table renderer and primitives for applications that need resizable columns, optional client-side sorting controls, and optional row virtualization. It is built on TanStack Table and TanStack Virtual, and does not require Bus Map or its design system.

Get started ​

  1. Confirm that the application uses the package's React peer version, 19.3.1.
  2. Install @busmap/table from the registry where your team publishes it.
  3. Import @busmap/table/style.css once in the application entry.
  4. Create typed columns and pass application data into useResizableTable.
tsx
import {
  createColumnHelper,
  ResizableTable,
  TableSortControls,
  resizableTableFeatures,
  useResizableTable,
} from "@busmap/table";

type Route = { id: string; name: string; destination: string };
const column = createColumnHelper<typeof resizableTableFeatures, Route>();
const columns = column.columns([
  column.accessor("name", { header: "Route", size: 160, minSize: 96 }),
  column.accessor("destination", { header: "Destination", minSize: 120 }),
]);

export function RouteTable({ rows }: { rows: Route[] }) {
  const table = useResizableTable({
    columns,
    data: rows,
    getRowId: route => route.id,
  });

  return (
    <>
      <TableSortControls table={table} label="Sort routes by" />
      <ResizableTable table={table} label="Bus routes" />
    </>
  );
}

useResizableTable enables the package's column-sizing and client-side sorting features. The renderer includes resize separators; virtualization is opt-in. Your application still owns data loading, domain rules, selection state, and feature orchestration.

React peer version

Prefer the latest stable React release, with matching React DOM and compatible type packages. The package currently declares react@19.3.1 as an exact peer dependency, matching the current Bus Map application. For newer React versions, validate compatibility and use a table release with a matching peer declaration. Do not bypass the peer check.
