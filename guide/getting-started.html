Getting started ​

Requirements ​

  • Node.js 24.13.0. The declared Yarn version is 1.22.22; this repository's documented build and documentation workflows use npm with package-lock.json. Run nvm install and nvm use in the checkout to select the pinned Node version.
  • A React application with the exact peer version declared by this release: react@19.3.1.
  • A package registry containing @busmap/table.
  • A bundler that resolves ESM package exports and CSS imports. No table-specific Vite plugin or framework configuration is required for a normal Vite React application.
  • TypeScript is optional at runtime. The package ships declarations and re-exports its TanStack Table types.

Prefer the latest stable React release for new integrations and upgrades, with matching React DOM and compatible types. This release's exact peer constraint still applies: adopting a newer React version requires compatibility validation and a table release whose peer declaration supports it. See starter-kit integration.

The package includes @tanstack/react-table@9.3.1 and @tanstack/react-virtual@3.14.26 as dependencies. They are not peer dependencies that consumers must install separately. React is the declared peer dependency; React DOM is not used as a package peer.

The package README currently documents publication through a configured Verdaccio registry. @busmap/table@0.1.1 does not resolve from the public npm registry at the time this guide was written. Use the registry your team publishes to; the localhost URL below is only an example of a local Verdaccio instance.

Create or update the consuming project's .npmrc:

ini
@busmap:registry=http://127.0.0.1:4873/

Then install from the project root:

sh
npm install @busmap/table

If the package is not published to a registry available to your project, build it from a checkout and consume the resulting tarball:

sh
# In the bus-map-table checkout
npm ci
npm run build
npm pack

Install the generated busmap-table-0.1.1.tgz from the consuming project using its local path:

sh
npm install /absolute/path/to/busmap-table-0.1.1.tgz

Load the stylesheet ​

Import the package stylesheet once from the application entry point:

ts
import "@busmap/table/style.css";

For Vite this can be in the module that creates the application root. The starter-kit snapshot uses app/src/index.render.tsx as its React render entry. Other bundlers must be configured to load CSS from dependencies, as they do for other imported stylesheets.

The stylesheet includes fallback values and can be used without Bus Map's design system. If the application has theme tokens, set the table variables or map compatible tokens on a wrapper; see Styling and themes.

Create and render a table ​

tsx
import {
  createColumnHelper,
  ResizableTable,
  TableSortControls,
  resizableTableFeatures,
  useResizableTable,
} from "@busmap/table";
import "@busmap/table/style.css";

type Vehicle = {
  id: string;
  route: string;
  stopCount: number;
};

const column = createColumnHelper<typeof resizableTableFeatures, Vehicle>();
const columns = column.columns([
  column.accessor("route", { header: "Route", size: 160, minSize: 96 }),
  column.accessor("stopCount", { header: "Stops", size: 96, minSize: 64 }),
]);

export function VehicleTable({ vehicles }: { vehicles: Vehicle[] }) {
  const table = useResizableTable({
    columns,
    data: vehicles,
    getRowId: vehicle => vehicle.id,
  });

  return (
    <section>
      <TableSortControls table={table} label="Sort vehicles by" />
      <ResizableTable table={table} label="Vehicles" />
    </section>
  );
}

Each column definition may provide size, minSize, and maxSize. The renderer enables resize separators for eligible columns. Explicit percentage columns share remaining space; otherwise the last resizable pixel column fills it. See sizing modes and permissions. TableSortControls lists sortable leaf columns with text headers and applies the configured client-side sorting feature.

Develop and build this repository ​

The repository uses npm and commits package-lock.json. The source package build uses Vite 8; use the repository's pinned Node.js 24.13.0.

sh
npm ci
npm run lint
npm test
npm run build
npm run docs:dev
npm run docs:build

npm run docs:build writes the production documentation site to docs/.vitepress/dist. The repository does not currently define a deployment workflow or a non-root hosting base path.
