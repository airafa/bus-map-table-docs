Column resizing ​

For separators between application modules rather than table columns, see Module resizing and draggable separators, including starterkit integration and air-gapped implementation.

For fixed widths, weighted expanding columns, independent resize permissions, RTL configuration, combinations, and controlled state, see the complete Pixel and percentage column sizing guide.

ResizableTable renders a focusable separator for each enabled leaf column with a valid resize action. Use native enableResizing: false to disable a column or enableColumnResizing: false to disable table-wide interaction. In an all-pixel table, the last resizable column fills the remaining width.

Set sizing constraints on column definitions:

tsx
const columns = column.columns([
  column.accessor("route", {
    header: "Route",
    size: 144,
    minSize: 96,
    maxSize: 280,
  }),
  column.accessor("destination", {
    header: "Destination",
    size: 240,
    minSize: 144,
  }),
]);

TanStack defaults are 150px initial size, 20px minimum, and Number.MAX_SAFE_INTEGER maximum. Set explicit bounds for application columns. size is an initial pixel size, not a resize permission flag.

Input ​

  • Pointer: drag with the primary pointer. Pixel columns update independently; percentage columns update their relative share using an enabled partner. Both modes respect pixel constraints and native columnResizeMode.
  • Keyboard: focus a separator. Left/Right Arrow changes the column by 2 pixels; Shift+Left/Right changes it by 10 pixels. Home and End move toward available bounds; End is capped by the current viewport/column width. Set columnResizeDirection: "rtl" for right-to-left layout and input.

If constrained column widths exceed the scroll viewport, the renderer allows horizontal scrolling. Explicit percentage columns absorb container growth; otherwise the all-pixel fallback does so. Fixed columns are never fallback targets.

Reuse the width calculation ​

resizeColumnPair(left, right, delta, leftMin, leftMax, rightMin, rightMax) returns a tuple containing the new left and right widths. A positive delta transfers width from the right column to the left; constraints clamp the transfer. The utility does not access the DOM or update a table state. The renderer uses it for constrained transfers; consumers that use it directly own validation of their inputs and application of the returned widths.

See the API reference for the full signature.
