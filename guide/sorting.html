Sorting ​

useResizableTable installs resizableTableFeatures, which includes TanStack's client-side row sorting feature and sorted row model. Place TableSortControls alongside the renderer to expose the package's standard sort selector and direction button.

tsx
const table = useResizableTable({
  columns,
  data,
  getRowId: row => row.id,
});

return (
  <>
    <TableSortControls table={table} label="Sort records by" />
    <ResizableTable table={table} label="Records" />
  </>
);

The controls provide an Unsorted option, a selector for sortable leaf columns, and a direction toggle. Selecting a column uses that column's TanStack first sort direction. Selecting Unsorted clears sorting. The direction button reverses the active direction and is disabled when no column is selected.

Requirements and behavior ​

  • A column must be sortable for it to appear in the selector. Use the column definitions and TanStack options to enable or disable sorting as needed.
  • Sortable column headers must be strings. The hook throws if a sortable column uses a non-string header because the control needs a text label.
  • The hook exposes only the first entry in the table sorting state. The built-in control therefore represents a single active sort column.
  • useResizableTable provides client-side sorting over the data given to the table. It does not fetch data, submit sort requests, or implement server-side sorting.
  • The sorted direction is exposed on rendered headers through aria-sort.

Custom header sort indicators ​

Pass renderSortIndicator from the parent to replace header chevrons. The callback receives "asc" or "desc" only for sorted columns. Without the prop, or when it returns null or undefined, the existing chevron is unchanged.

tsx
<ResizableTable
  table={table}
  label="Records"
  renderSortIndicator={direction => (
    <svg viewBox="0 0 24 24" focusable="false">
      <path d={direction === "desc"
        ? "M8 5v14m-4-4 4 4 4-4M15 7h2M15 12h4M15 17h5"
        : "M8 19V5m-4 4 4-4 4 4M15 7h5M15 12h4M15 17h2"} />
    </svg>
  )}
/>

You can return the same application-owned icon component used in your sorting toolbar. This changes presentation only: sorting, aria-sort, and the decorative aria-hidden wrapper remain intact. Do not return an interactive button. The standalone package does not import an icon library. For compound primitives, pass custom content as Table.SortIndicator children.

Custom sorting controls ​

For custom controls, use useTableSortingControls(table) and render its options, sort, direction, selectColumn, and toggleDirection values. See Public API.

If using the lower-level TanStack hook instead, pass the feature set explicitly:

tsx
const table = useTable({
  columns,
  data,
  features: resizableTableFeatures,
  getRowId: row => row.id,
});

With useTable, the consumer is responsible for providing the feature set and all other TanStack options required by its configuration.
