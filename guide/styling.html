Styling and themes ​

Import the stylesheet once:

ts
import "@busmap/table/style.css";

The package has no dependency on @busmap/design-system and no theme provider. Its CSS uses custom properties with fallbacks, so a consumer can use the defaults or bridge its theme tokens to the table variables. Set variables on the ResizableTable scroll container through style, on an ancestor, or on the application theme root.

tsx
<ResizableTable
  table={table}
  label="Bus routes"
  style={{
    "--table-row-height": "40px",
    "--table-header-background": "var(--color-surface-raised, #fff)",
    "--table-row-selected": "var(--color-surface-selected, #e8f0ff)",
    "--table-row-selected-edge": "var(--color-border-focus, #275dad)",
  }}
/>

TableCSSProperties extends React's CSSProperties with the package-specific custom properties. For a global theme, declare the variables in CSS instead:

css
.application-theme {
  --table-row-height: 40px;
  --table-cell-padding-x: 0.75rem;
  --table-header-background: var(--color-surface-raised);
  --table-label: var(--color-text-primary);
  --table-row-border: var(--color-border-subtle);
}

The package does not supply these application color tokens; map them to tokens that your project actually defines. A missing custom token may fall back to currentColor or a transparent background and still render.

Compose primitives ​

Use Table when the consumer needs to map its own rows and cells rather than use ResizableTable:

tsx
import { Table } from "@busmap/table";

<Table.Root aria-label="Route summary">
  <Table.Header>
    <Table.HeaderRow>
      <Table.Head><Table.HeaderLabel>Route</Table.HeaderLabel></Table.Head>
      <Table.Head><Table.HeaderLabel>Destination</Table.HeaderLabel></Table.Head>
    </Table.HeaderRow>
  </Table.Header>
  <Table.Body>
    {routes.map(route => (
      <Table.Row key={route.id}>
        <Table.Cell>{route.name}</Table.Cell>
        <Table.Cell>{route.destination}</Table.Cell>
      </Table.Row>
    ))}
  </Table.Body>
</Table.Root>

These are styled DOM primitives, not a data adapter. Manual composition does not add TanStack sorting, resize separators, row virtualization, or data management. The consumer must supply correct keys, accessible names, and any interactive behavior. Add className, inline styles, or target a stable data-slot to customize individual primitives.
